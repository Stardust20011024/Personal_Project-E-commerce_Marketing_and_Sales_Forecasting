# 电商营销与销售预测项目说明

## 项目背景

本项目分为两个部分，旨在通过数据分析优化电商平台的营销策略和库存管理。

## Part 1：用户转化分析与营销时间优化

电商平台计划通过信息向潜在用户发送广告和优惠信息，以吸引用户注册并完成购买。

我们拥有三份数据集：  
	1.	user_behavior_time_resampled.csv：用户行为表  
	2.	vip_user.csv：VIP会员信息表  
	3.	user_info.csv：用户基本信息表  

### 目标：
- 分析最有可能完成转化的用户特征（年龄、性别、地域等）。
- 分析用户行为数据，确定发送营销短信的最佳时间，以提高转化率。

## Part 2：商品销量预测与库存管理

在促销活动开始前三天，用户只能浏览或加入购物车，无法下单；促销正式开始后用户才能下单。

### 目标：
- 基于用户在三天预热期的行为数据，预测各商品的销量。
- 帮助平台合理备货，避免因供应不足导致缺货问题。
